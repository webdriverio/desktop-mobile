### New:

- **Element helpers installed once per page**: The driver's page-side helpers load once, from the page's `<head>`, instead of in every script, so a typed character's script drops from about 26 KB to under 4 KB. Pages can see them as `window.__wdio_element_events` ([#977](https://github.com/webdriverio/desktop-mobile/pull/977))

### Breaking Changes:

- **Update the Dioxus crates together**: The driver requires `wdio-dioxus-bridge` 2.x, and `wdio-dioxus` 2.0 requires this driver at 2.x. Use it with `@wdio/dioxus-service` 2.0, which supports WebdriverIO v9 and v10 (`^9.33.0 || ^10.2.0`). See [Update the crates together](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#update-the-crates-together)
- **Screenshots fail with `unsupported operation`**: Page and element screenshots throw, where they returned a blank image. Real screenshots come in a 2.x minor. See [Screenshots](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#screenshots) ([#891](https://github.com/webdriverio/desktop-mobile/pull/891))
- **Clear, Send Keys and Click**: Send Keys no longer fires `change` while the field keeps focus, Clear leaves the field blurred, and Click fires pointer and mouse events before `click`, with `isPrimary: false`. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#clear-send-keys-and-click) ([#871](https://github.com/webdriverio/desktop-mobile/pull/871), [#1041](https://github.com/webdriverio/desktop-mobile/pull/1041))
- **When `change` fires**: A field edited by key actions fires `change` when focus leaves it, and an owed `change` fires before the page's own `blur` listeners. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#when-change-fires) ([#964](https://github.com/webdriverio/desktop-mobile/pull/964), [#1041](https://github.com/webdriverio/desktop-mobile/pull/1041))
- **Key codes and Shift**: Key actions send the browser's `keyCode`, `code` and Shift, and with Shift held, keys send and type the shifted character. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#key-codes-and-shift) ([#897](https://github.com/webdriverio/desktop-mobile/pull/897), [#919](https://github.com/webdriverio/desktop-mobile/pull/919))
- **Key actions type text**: Key actions type and delete in the focused field, break lines, select all and step radio buttons. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#key-actions-type-text) ([#920](https://github.com/webdriverio/desktop-mobile/pull/920))
- **Send Keys presses special keys**: Special keys in `setValue()` and `addValue()` press keys instead of being written into the element, and only text fields and contenteditables take text. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#send-keys-presses-special-keys) ([#922](https://github.com/webdriverio/desktop-mobile/pull/922))
- **Enter and Space**: Enter in a form's input submits the form, and Enter or Space on a focused button clicks it. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#enter-and-space) ([#898](https://github.com/webdriverio/desktop-mobile/pull/898), [#910](https://github.com/webdriverio/desktop-mobile/pull/910))
- **Tab moves focus**: Tab and Shift+Tab move focus in Chrome's order, and a tab character presses Tab. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#tab) ([#924](https://github.com/webdriverio/desktop-mobile/pull/924))
- **Release Actions order**: Held keys and pointer buttons are released together, latest press first. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#release-actions) ([#978](https://github.com/webdriverio/desktop-mobile/pull/978))
- **Elements in script results**: Execute Script and Execute Async Script return a DOM element or shadow root as a W3C reference, where they returned `{}`, and a `NodeList` as an array. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#elements-in-script-results) ([#1016](https://github.com/webdriverio/desktop-mobile/pull/1016))
- **Focus on Windows**: The driver relies on the bridge's WebView2 focus emulation, so focus moves fire `focus` and `blur` in a background window. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#focus-on-windows) ([#965](https://github.com/webdriverio/desktop-mobile/pull/965))
- **`ActionState::pressed_keys` is a method**: It returns the held keys in press order. Apps that only call `install` don't notice. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#actionstatepressed_keys-is-a-method) ([#910](https://github.com/webdriverio/desktop-mobile/pull/910))

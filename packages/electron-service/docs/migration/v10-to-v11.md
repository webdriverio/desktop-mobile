# Migration Guide: v10 → v11

What changes when you upgrade from v10 to v11, and what to do about it.

## Breaking Changes

### Which app build is used

The service now finds Electron Builder apps built for Windows ARM64 and ia32 (`win-arm64-unpacked`, `win-ia32-unpacked`). It also follows Electron Builder's `defaultArch`: with `win.defaultArch: 'arm64'`, it finds the x64 build in `win-x64-unpacked`.

When your output directory holds builds for more than one architecture, the service now launches the one built for the machine running the tests, so your tests may launch a different app:

| Machine running the tests | Builds in the output directory            | v10 launched                        | v11 launches         |
| ------------------------- | ----------------------------------------- | ----------------------------------- | -------------------- |
| Windows ARM64             | `win-unpacked`, `win-arm64-unpacked`      | `win-unpacked`                      | `win-arm64-unpacked` |
| Linux x64                 | `linux-unpacked`, `linux-arm64-unpacked`  | `linux-arm64-unpacked`              | `linux-unpacked`     |
| Linux x64                 | `linux-unpacked`, `linux-armv7l-unpacked` | `linux-armv7l-unpacked`             | `linux-unpacked`     |
| Intel Mac                 | `mac`, `mac-arm64`                        | `mac-arm64`                         | `mac`                |
| Intel Mac                 | `mac`, `mac-universal`                    | `mac-universal`                     | `mac`                |
| Intel Mac                 | `mac-arm64`, `mac-universal`              | `mac-arm64`                         | `mac-universal`      |
| Apple Silicon Mac         | Forge `darwin-x64`, `darwin-arm64`        | `darwin-x64`                        | `darwin-arm64`       |
| Linux ARM64               | Forge `linux-x64`, `linux-arm64`          | `linux-x64`                         | `linux-arm64`        |
| Windows ARM64             | Forge `win32-x64`, `win32-arm64`          | `win32-x64`                         | `win32-arm64`        |
| Windows x64               | Forge `win32-ia32`, `win32-x64`           | `win32-ia32` (Electron 43 or older) | `win32-x64`          |

A machine running an x64 Node.js counts as x64, including an Apple Silicon Mac under Rosetta and a Windows ARM64 machine under emulation.

v11 also finds Electron Forge builds that v10 missed. v10 looked only for x64 builds when `browserVersion` held a Chromium version or the Electron version was unknown, and from Electron 44 it skipped `win32-ia32` and `linux-armv7l`.

To keep launching a specific build, set [`appBinaryPath`](../configuration.md#appbinarypath). See [Which build is used](../configuration.md#which-build-is-used) for the full order.

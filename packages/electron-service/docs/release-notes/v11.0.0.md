### New:

- **WebdriverIO v10**: The service runs on WebdriverIO v10 as well as v9. See [WebdriverIO v10](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#webdriverio-v10) ([#792](https://github.com/webdriverio/desktop-mobile/pull/792), [#794](https://github.com/webdriverio/desktop-mobile/pull/794), [#724](https://github.com/webdriverio/desktop-mobile/pull/724))
- **Windows ARM64 and ia32 builds**: The service finds Electron Builder apps in `win-arm64-unpacked` and `win-ia32-unpacked`, follows Electron Builder's `defaultArch`, and finds Electron Forge builds that v10 missed ([#1039](https://github.com/webdriverio/desktop-mobile/pull/1039))
- **Warning for a build the machine can't run**: When the only app build found is for another architecture, such as `mac-arm64` on an Intel Mac, the service still launches it and logs a warning that says which build to make, or to set `appBinaryPath` ([#1045](https://github.com/webdriverio/desktop-mobile/pull/1045))
- **`connectionRetryTimeout` in standalone mode**: `startWdioSession()` takes it in its second argument and passes it to WebdriverIO. Without it, the session uses WebdriverIO's default ([#883](https://github.com/webdriverio/desktop-mobile/pull/883))
- **Weston on Linux**: On WebdriverIO v10, the testrunner starts Weston if it's installed and Xvfb otherwise. The service is tested on both and needs no setting ([#809](https://github.com/webdriverio/desktop-mobile/pull/809), [#876](https://github.com/webdriverio/desktop-mobile/pull/876), [#878](https://github.com/webdriverio/desktop-mobile/pull/878), [#890](https://github.com/webdriverio/desktop-mobile/pull/890))

### Breaking Changes:

- **WebdriverIO 9.33.0+**: On WebdriverIO v9, the service needs 9.33.0 or later, and on v10, 10.2.0 or later (`^9.33.0 || ^10.2.0`). See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#webdriverio-9330) ([#1015](https://github.com/webdriverio/desktop-mobile/pull/1015))
- **Node.js 22.23.4+, 24.22.1+ or 26.12.1+**: The same range as WebdriverIO 10, as the services follow WebdriverIO's Node.js support. 23.x and 25.x aren't supported. Older versions trust the compromised eMudhra intermediate CAs. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#nodejs) ([#797](https://github.com/webdriverio/desktop-mobile/pull/797), [#916](https://github.com/webdriverio/desktop-mobile/pull/916))
- **Optional peers**: `webdriverio`, `@wdio/globals` and `@wdio/types` are optional peers. Standalone mode needs `webdriverio` and `@wdio/globals` installed next to the service. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#optional-peer-dependencies) ([#798](https://github.com/webdriverio/desktop-mobile/pull/798))
- **Which app build is used**: With builds for more than one architecture, the service launches the one built for the machine running the tests, so your tests may launch a different app. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#which-app-build-is-used) ([#1039](https://github.com/webdriverio/desktop-mobile/pull/1039))
- **`getBinaryPath()`**: Takes no Electron version. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#getbinarypath-takes-no-electron-version) ([#1039](https://github.com/webdriverio/desktop-mobile/pull/1039))
- **Removed mock overloads**: `mock(apiName, funcName, returnValue)` and `isMockFunction(name: string)` are gone from the types; neither worked. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#removed-mock-and-ismockfunction-overloads) ([#801](https://github.com/webdriverio/desktop-mobile/pull/801))
- **Bulk mock failures**: A failed bulk mock operation attempts every mock, then throws one error listing every failure. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#bulk-mock-operations-report-every-failure) ([#744](https://github.com/webdriverio/desktop-mobile/pull/744))
- **`undefined` arguments in call data**: A mock's recorded calls keep `undefined` arguments, where they used to become `null`. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#undefined-arguments-in-call-data) ([#1044](https://github.com/webdriverio/desktop-mobile/pull/1044))
- **`withImplementation()`**: An async callback keeps the temporary implementation until its promise settles, the callback takes only the `electron` object, and the call rejects when the callback throws. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#withimplementation) ([#896](https://github.com/webdriverio/desktop-mobile/pull/896))
- **Browser mode `mock(channel)`**: Calling it again resets the existing mock, as native mode does. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#browser-mode-mockchannel-resets-an-existing-mock) ([#1024](https://github.com/webdriverio/desktop-mobile/pull/1024))
- **`devServer`**: A service-level option only. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#devserver-is-a-service-level-option) ([#953](https://github.com/webdriverio/desktop-mobile/pull/953))
- **CDP bridge connection errors**: When the bridge can't connect, `browser.electron` calls throw a new message with the connection error as its cause, and a refused `localhost` connection lists the addresses it tried. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#cdp-bridge-connection-errors) ([#814](https://github.com/webdriverio/desktop-mobile/pull/814))
- **Multiremote mocks**: Each instance's mocks only mock that instance's app, and an instance's bulk mock operations and `clearMocks`, `resetMocks` and `restoreMocks` options only touch its own mocks. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#mocks-per-instance) ([#923](https://github.com/webdriverio/desktop-mobile/pull/923))
- **Multiremote instance options**: `mode`, the log capture options and `triggerDeeplink()`'s settings in an instance's `wdio:electronServiceOptions` take effect, where they were ignored. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#instance-options-take-effect) ([#952](https://github.com/webdriverio/desktop-mobile/pull/952))
- **Multiremote `triggerDeeplink()` on macOS**: Throws when two instances run the same app. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#triggerdeeplink-on-macos) ([#1043](https://github.com/webdriverio/desktop-mobile/pull/1043))
- **Standalone `devServer`**: A second session in the same process can't use a command-form `devServer` at the same URL until the first session's cleanup stops it. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-electron-service@v11.0.0/packages/electron-service/docs/migration/v10-to-v11.md#concurrent-sessions-with-a-command-devserver) ([#864](https://github.com/webdriverio/desktop-mobile/pull/864))

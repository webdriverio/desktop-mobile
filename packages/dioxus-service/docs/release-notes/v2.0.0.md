### New:

- **WebdriverIO v10 support**: The service runs on WebdriverIO v9 and v10. Multiremote, mock sync and browser mode work on both ([#792](https://github.com/webdriverio/desktop-mobile/pull/792), [#798](https://github.com/webdriverio/desktop-mobile/pull/798), [#1015](https://github.com/webdriverio/desktop-mobile/pull/1015))
- **`mock.withImplementation()`**: Runs a callback in the app's webview with a temporary implementation, and resolves to the callback's result. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#withimplementation) ([#901](https://github.com/webdriverio/desktop-mobile/pull/901), [#896](https://github.com/webdriverio/desktop-mobile/pull/896))
- **Typed `invoke`**: `invoke` in an `execute()` script takes the result type as a generic, and `execute()` resolves to the script's awaited return type ([#896](https://github.com/webdriverio/desktop-mobile/pull/896))
- **`connectionRetryTimeout` in standalone mode**: `startWdioSession()` takes WebdriverIO's request timeout with the service options ([#883](https://github.com/webdriverio/desktop-mobile/pull/883))

### Breaking Changes:

- **WebdriverIO v9 and v10**: Both are supported, from 9.33.0 and 10.2.0 (`^9.33.0 || ^10.2.0`). See [WebdriverIO v9 and v10](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#webdriverio-v9-and-v10) ([#1015](https://github.com/webdriverio/desktop-mobile/pull/1015))
- **Node.js 22.23.4+, 24.22.1+ or 26.12.1+**: Node.js 23.x and 25.x aren't supported. See [Node.js](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#nodejs) ([#797](https://github.com/webdriverio/desktop-mobile/pull/797), [#916](https://github.com/webdriverio/desktop-mobile/pull/916))
- **Optional peers**: `webdriverio` and `@wdio/types` are optional peers. In standalone mode, install `webdriverio` next to the service. See [optional peers](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#webdriverio-packages-are-optional-peers) ([#798](https://github.com/webdriverio/desktop-mobile/pull/798), [#724](https://github.com/webdriverio/desktop-mobile/pull/724))
- **Rust crates 2.0**: Update `wdio-dioxus` to `"2"`, with the service. The crates require 2.x of each other. See [Rust crates](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#update-the-crates-together)
- **`commandTimeout` and `rootDir` removed**: Neither took effect. Set WebdriverIO's `connectionRetryTimeout` instead. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#commandtimeout-and-rootdir-removed) ([#832](https://github.com/webdriverio/desktop-mobile/pull/832), [#947](https://github.com/webdriverio/desktop-mobile/pull/947))
- **`'dioxus:options'.args`**: Now reaches the app, and replaces `appArgs` for that capability. `webviewOptions` is removed. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#dioxusoptionsargs-replaces-appargs) ([#946](https://github.com/webdriverio/desktop-mobile/pull/946))
- **`driverProvider` per capability**: A capability that sets or inherits `'external'`, or an unknown value, fails at startup. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#driverprovider-per-capability) ([#949](https://github.com/webdriverio/desktop-mobile/pull/949))
- **`embeddedPort` is a preferred port**: A busy port is skipped for a free one. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#embeddedport-is-a-preferred-port) ([#807](https://github.com/webdriverio/desktop-mobile/pull/807))
- **Mocks per multiremote instance**: Each instance's `mock()` gets its own mock, and bulk operations on an instance only touch its mocks. See [Mocking](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#each-multiremote-instance-has-its-own-mocks) ([#921](https://github.com/webdriverio/desktop-mobile/pull/921))
- **`clearMocks`, `resetMocks` and `restoreMocks` take effect**: They used to do nothing; now they run before each test. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#clearmocks-resetmocks-and-restoremocks-take-effect) ([#921](https://github.com/webdriverio/desktop-mobile/pull/921))
- **Bulk mock failures**: A failed bulk mock operation attempts every mock, then throws one error listing every failure. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#bulk-mock-failures) ([#744](https://github.com/webdriverio/desktop-mobile/pull/744))
- **`undefined` in call data**: Recorded calls keep `undefined` arguments, where they became `null`. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#undefined-arguments-in-call-data) ([#1044](https://github.com/webdriverio/desktop-mobile/pull/1044))
- **`withImplementation()` runs in the app**: The callback gets `dx` and can't use `browser`. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#withimplementation) ([#901](https://github.com/webdriverio/desktop-mobile/pull/901), [#896](https://github.com/webdriverio/desktop-mobile/pull/896))
- **Elements in script results**: `browser.execute()` and `browser.dioxus.execute()` return a DOM element as a W3C element reference, where they returned `{}`. See the [migration guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#elements-in-script-results) ([#1016](https://github.com/webdriverio/desktop-mobile/pull/1016))
- **Embedded driver behaviour**: Screenshots fail with `unsupported operation`, and Click, Clear, Send Keys and key actions fire the events Chrome fires. See [Embedded driver behaviour](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#embedded-driver-behaviour)
- **`triggerDeeplink()` throws where it can't deliver**: In multiremote when two instances run the same app, and in browser mode. See [Deeplinks](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#deeplinks) ([#1043](https://github.com/webdriverio/desktop-mobile/pull/1043), [#1058](https://github.com/webdriverio/desktop-mobile/pull/1058))
- **Browser mode per capability**: Each capability opens its own `devServerUrl`, mixed `mode` values stop the run, and `devServer` is a service-level option only. See [Browser mode](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#browser-mode) ([#953](https://github.com/webdriverio/desktop-mobile/pull/953))
- **Standalone sessions**: `startWdioSession()` uses WebdriverIO's request timeout and retries, `cleanupWdioSession()` runs `after` and `afterSession` before deleting the session, and a command-form `devServer` isn't shared between sessions. See [Standalone mode](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#standalone-mode) ([#883](https://github.com/webdriverio/desktop-mobile/pull/883), [#864](https://github.com/webdriverio/desktop-mobile/pull/864))

### Fixed:

- `browser.dioxus.execute()` on the multiremote root resolves with each instance's result, without the embedded driver's envelope ([#955](https://github.com/webdriverio/desktop-mobile/pull/955))
- Standalone `startWdioSession()` honours `startTimeout` and the log options passed in its second argument ([#816](https://github.com/webdriverio/desktop-mobile/pull/816))
- A failed `mockClear()` or `mockReset()` leaves the test-side mock unchanged, and `mockRestore()` removes the mock even when the app can't be reached ([#744](https://github.com/webdriverio/desktop-mobile/pull/744))
- The service writes to WebdriverIO's log file instead of a second logger's ([#724](https://github.com/webdriverio/desktop-mobile/pull/724))

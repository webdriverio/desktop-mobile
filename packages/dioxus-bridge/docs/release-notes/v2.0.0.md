Covers the `wdio-dioxus-bridge` crate and the `@wdio/dioxus-bridge` npm package.

### New:

- **`on_window(window, dom)`**: Registers a window with WebdriverIO and, for the embedded driver, turns on WebView2's focus emulation on Windows. Call it from an app's own `with_on_window` callback, or use `wdio_dioxus::on_window` ([#965](https://github.com/webdriverio/desktop-mobile/pull/965))
- **WebView2 focus emulation**: When the embedded driver is installed, the bridge turns on focus emulation on Windows, so focus moves fire `focus` and `blur` in a background window ([#965](https://github.com/webdriverio/desktop-mobile/pull/965))
- **`install_with_embedded_port_registry_and_page_js()`**: Runs a script from its own `<script>` in each page's `<head>`, ahead of the page's scripts. `wdio-dioxus-embedded-driver` 2.0 uses it to install its element helpers once per page ([#977](https://github.com/webdriverio/desktop-mobile/pull/977))

### Breaking Changes:

- **Node.js 22.23.4+, 24.22.1+ or 26.12.1+** (`@wdio/dioxus-bridge`): Node.js 23.x and 25.x aren't supported. The package runs in the app, so the floor only constrains the app's build. See [Node.js](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#nodejs) ([#797](https://github.com/webdriverio/desktop-mobile/pull/797), [#916](https://github.com/webdriverio/desktop-mobile/pull/916))
- **Update the Dioxus crates together**: `wdio-dioxus` and `wdio-dioxus-embedded-driver` 2.0 require this bridge at 2.x. See [Update the crates together](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#update-the-crates-together)
- **`with-bridge` feature removed**: It never did anything. Delete it from your manifest. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#with-bridge-feature-removed) ([#719](https://github.com/webdriverio/desktop-mobile/pull/719))
- **Apps with their own `with_on_window`**: An app whose callback calls `window_state::register_window` gets no focus emulation; call `on_window` instead. See [the guide](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#apps-with-their-own-window-callback) ([#965](https://github.com/webdriverio/desktop-mobile/pull/965))
- **Always focused on Windows**: With focus emulation on, the page stays focused and visible: switching windows fires no window `focus` or `blur`, a minimized window fires no `visibilitychange`, and its timers aren't slowed. See [Focus on Windows](https://github.com/webdriverio/desktop-mobile/blob/wdio-dioxus-service@v2.0.0/packages/dioxus-service/docs/migration/v1-to-v2.md#focus-on-windows) ([#965](https://github.com/webdriverio/desktop-mobile/pull/965))

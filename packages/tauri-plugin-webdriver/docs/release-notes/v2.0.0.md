### Breaking Changes:

- **WebdriverIO v9 and v10**: `tauri-plugin-wdio-webdriver` 2.0 pairs with `@wdio/tauri-service` 2.0, which supports both, with `webdriverio` `^9.33.0 || ^10.2.0`. Update it together with the service and `tauri-plugin-wdio`. See [Update the service, the plugin and the embedded driver together](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#update-the-service-the-plugin-and-the-embedded-driver-together) ([#1015](https://github.com/webdriverio/desktop-mobile/pull/1015))
- **`change` when focus leaves**: Element Clear and Element Send Keys no longer fire `change` while the field keeps focus. It fires when focus leaves the field, or when Enter commits an input. See [`change` fires when focus leaves the field](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#change-fires-when-focus-leaves-the-field) ([#827](https://github.com/webdriverio/desktop-mobile/pull/827))
- **Element Clear**: Leaves the field blurred, and refuses an element it can't clear with `invalid element state`. See [Clear blurs the field](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#clear-blurs-the-field-and-refuses-non-editable-elements) ([#827](https://github.com/webdriverio/desktop-mobile/pull/827))
- **Element Click events**: Fires `pointerdown`, `mousedown`, `pointerup` and `mouseup` before `click`, and moves focus as a click does. Its `click` has `isPrimary: false`. See [Element Click fires pointer and mouse events](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#element-click-fires-pointer-and-mouse-events) ([#827](https://github.com/webdriverio/desktop-mobile/pull/827), [#1041](https://github.com/webdriverio/desktop-mobile/pull/1041))
- **Key codes**: Printable keys send the browser's `keyCode`, `code` and Shift (`a` is 65, not 97), and a newline or `\b` is the Enter or Backspace key. See [Key codes, newlines and Backspace](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#key-codes-newlines-and-backspace) ([#828](https://github.com/webdriverio/desktop-mobile/pull/828))
- **Shift**: With Shift held, a key sends and types the shifted character. See [Shift sends the shifted character](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#shift-sends-the-shifted-character) ([#919](https://github.com/webdriverio/desktop-mobile/pull/919))
- **Tab**: Tab moves focus and Shift+Tab moves it back, and a tab character presses Tab. See [Tab moves focus](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#tab-moves-focus) ([#924](https://github.com/webdriverio/desktop-mobile/pull/924))
- **Enter submits forms**: Enter in a form's input submits the form, as a user's Enter does. See [Enter submits the form](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#enter-submits-the-form) ([#898](https://github.com/webdriverio/desktop-mobile/pull/898))
- **Enter and Space on buttons**: Enter or Space on a focused button clicks it. See [Enter and Space click a focused button](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#enter-and-space-click-a-focused-button) ([#910](https://github.com/webdriverio/desktop-mobile/pull/910))
- **Key actions owe a `change`**: A field edited by `browser.keys()` fires `change` when focus leaves it, and a key types in the element a `keydown` handler moved focus to. The owed `change` fires before the page's own `blur` and `focusout` listeners. See [Fields edited by `browser.keys()` owe a `change`](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#fields-edited-by-browserkeys-owe-a-change) ([#964](https://github.com/webdriverio/desktop-mobile/pull/964), [#1041](https://github.com/webdriverio/desktop-mobile/pull/1041))
- **Release Actions order**: Held keys and pointer buttons are released together, latest press first. See [`releaseActions()` releases in reverse press order](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#releaseactions-releases-in-reverse-press-order) ([#978](https://github.com/webdriverio/desktop-mobile/pull/978))
- **WebView2 focus emulation**: On Windows, the driver emulates page focus, so focus moves fire `focus` and `blur` in a background window. See [Windows: page focus is emulated](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#windows-page-focus-is-emulated) ([#965](https://github.com/webdriverio/desktop-mobile/pull/965))
- **Element references in script results**: Execute Script returns a DOM element or shadow root as a W3C reference, where it returned `null` or `{}`, and any iterable with a numeric `length` as an array. The same applies to `browser.tauri.execute()` through the driver. See [`browser.execute()` returns elements as references](https://github.com/webdriverio/desktop-mobile/blob/wdio-tauri-service@v2.0.0/packages/tauri-service/docs/migration/v1-to-v2.md#browserexecute-returns-elements-as-references) ([#1016](https://github.com/webdriverio/desktop-mobile/pull/1016), [#1042](https://github.com/webdriverio/desktop-mobile/pull/1042))

### Fixed:

- On macOS, Execute Async Script runs through the polling Execute Script path, so it no longer hangs when WebKit reclaims its completion handler ([#796](https://github.com/webdriverio/desktop-mobile/pull/796))
- On Linux, an async script that never calls `done` fails with `script timeout`, not `javascript error` ([#1035](https://github.com/webdriverio/desktop-mobile/pull/1035))
- The crate declares `rust-version` 1.83, the lowest its dependencies build with ([#1002](https://github.com/webdriverio/desktop-mobile/pull/1002))

### Developer:

- **Testing**: Focus events checked in windows without OS focus ([#1004](https://github.com/webdriverio/desktop-mobile/pull/1004)); Rust formatting checked with `rustfmt` ([#727](https://github.com/webdriverio/desktop-mobile/pull/727))
- **Dependencies**: Updated Cargo dependencies ([#818](https://github.com/webdriverio/desktop-mobile/pull/818), [#982](https://github.com/webdriverio/desktop-mobile/pull/982))
